# 🏆 Task Master 3000

A full-stack Task Management application built to demonstrate **C.R.U.D.** operations (Create, Read, Update, Delete).
Connecting a **Java Spring Boot** backend with a **React (Vite)** frontend.

## 🚀 Features
* **Create:** Add new tasks to the database.
* **Read:** View tasks efficiently.
* **Update:** Mark tasks as completed (Real-time status updates).
* **Delete:** Remove tasks permanently.
* **Architecture:** REST API communication with JSON.

## 🛠️ Tech Stack
* **Backend:** Java 17, Spring Boot 3, Spring Data JPA, H2 Database.
* **Frontend:** React, Vite, Axios, CSS Modules.

## ⚙️ How to Run
1. **Backend:** Open `backend` in IntelliJ and run `TaskMasterBackendApplication`.
2. **Frontend:** Open `frontend` in VS Code, run `npm install`, then `npm run dev`.
